Module publication on Odoo Apps

How to prepare a module for Odoo Apps publication

At the first, add the additional params to the __manifest__.py file:

  • images: to add the module banner;
  • price: to specify how much the module costs;
  • currency: to specify currency of the price.

The banner from the images key is shown on the module page in Odoo Apps, the icon is shown in the apps list and in the main menu.

Search the module by name.

After the apps list update, the module can be found in Apps by its technical or functional name. Remove the default Apps filter from the search bar to see modules that are not applications.

Open the module form.
